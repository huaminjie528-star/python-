# 五分钟现场演示提纲

现场必须操作安装版。默认离线模式仅用于自检，随机需求必须提前配置真实模型。

| 时间 | 操作 | 要说明的事 |
|---|---|---|
| 0:00–0:30 | 从应用程序文件夹双击 Little Cursor，打开老师提供的项目 | 带标题栏的桌面应用，UI 资源随包分发 |
| 0:30–3:00 | 真实模型模式输入老师的需求，先读取，查看 diff，批准修改，再批准测试 | 模型决定下一步，执行器掌握实际权限；用真实测试判断结果 |
| 3:00–4:00 | 在一个含两处相同文本的文件上请求局部替换，展示不唯一报错和补读后的恢复 | old 必须唯一，不能猜测；失败记录保留并标红 |
| 4:00–4:40 | 请求“调用 MCP 获取作业验收清单”，展开外部工具记录 | 工具来自独立 server，通过初始化、发现和调用接入，前缀用于路由 |
| 4:40–5:00 | 说明最不满意的地方 | 审批频繁、缺少系统沙箱，后续优先改进执行隔离 |

如果需要主动展示中断，离线模式输入“测试中断”，批准 sleep 命令后点击“中断”。应看到 cancelled 和本轮停止，而非仅把按钮置灰。

答辩要点：

- 不唯一时报错，是因为执行器不能确定用户要求的目标位置。read 后扩大 old 的上下文，再唯一替换。
- 相同工具与参数累计调用超过三次就停止，另有步数、调用次数和时间预算。相似参数变化仍可能绕过重复计数，所以还需要总预算。
- 内置工具仅在四项白名单中；MCP 工具使用 `mcp__server__tool` 路由至独立子进程。不是依靠 UI 上的文字判断来源。

本次 `demo.mp4` 是安装版实际操作的截图采样回放，没有配音。底部注明离线验收与截图采样，展示修复、失败恢复、MCP 和中断。它不等同于连续录屏或真实模型验收。正式提交前，建议本人配置 Key 后依照上表录制带讲解的真实模型版本。

采样画面保存在本地 `.local-data/recording/`，`scripts/encode_demo.py` 用 `imageio-ffmpeg==0.6.0` 编码。该依赖只用于制视频，不是桌面运行依赖，不放进应用包。
